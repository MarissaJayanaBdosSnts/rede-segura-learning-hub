
Rede Segura
Educação em Segurança Digital e Privacidade para Pessoas Trans e LGBTQIA+

O Rede Segura é um projeto educativo que busca ampliar o conhecimento sobre segurança digital, privacidade e enfrentamento da violência online. O portal reúne orientações para reconhecer riscos, adotar medidas de proteção e encontrar canais adequados de denúncia e apoio.
Acesse o projeto
- Site publicado: https://rede-segura-learning-hub.lovable.app
- Repositório: https://github.com/MarissaJayanaBdosSnts/rede-segura-learning-hub
Objetivo
Oferecer informações acessíveis e orientações práticas sobre situações de violência e exposição no ambiente digital, com atenção especial às vulnerabilidades enfrentadas por pessoas trans e LGBTQIA+.
Conteúdos do portal
O site está organizado em três temas educativos:
1. Doxxing e exposição de dados pessoais — explica o que é a exposição de informações privadas sem consentimento, seus riscos e formas de prevenção.
2. Discurso de ódio e denúncia — aborda manifestações discriminatórias e orienta sobre como denunciar conteúdos abusivos e buscar apoio.
3. Imagens íntimas e deepfakes — apresenta riscos relacionados à divulgação não consentida de imagens e à manipulação de conteúdo por inteligência artificial.
O portal também conta com áreas de apoio:
- Central de Proteção Digital: orientações sobre privacidade, contas, aplicativos e compartilhamento de informações.
- Central de Denúncias e Ajuda: reúne caminhos para buscar orientação e denunciar violações.
- Sobre o projeto: apresenta a proposta e os objetivos da iniciativa.
Os conteúdos devem ser utilizados para fins educativos. Em situações reais, consulte os canais oficiais e procure ajuda adequada. Os exemplos usados no projeto devem ser fictícios e identificados como simulações.

Público-alvo
Pessoas trans e LGBTQIA+, além de familiares, educadores, profissionais e pessoas interessadas em aprender sobre segurança digital, privacidade e respeito na internet.
Tecnologias utilizadas
- React — construção da interface.
- TypeScript — tipagem e organização do código.
- Vite — ferramenta de desenvolvimento e build.
- TanStack Router — navegação entre páginas.
- Tailwind CSS — estilização da interface.
- Lucide React — ícones.

Como executar localmente
Pré-requisitos
- Node.js instalado.
- npm (instalado junto com o Node.js).
- Git instalado para clonar o repositório.
1. Clone o repositório
git clone https://github.com/MarissaJayanaBdosSnts/rede-segura-learning-hub.git
2. Entre na pasta do projeto
cd rede-segura-learning-hub
3. Instale as dependências
npm install
4. Inicie o servidor de desenvolvimento
npm run dev
O terminal exibirá o endereço local para abrir o site no navegador.
5. Gere a versão de produção
npm run build
Para visualizar localmente a versão gerada:
npm run preview
